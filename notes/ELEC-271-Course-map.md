# ELEC 271: Course map

## Digital Systems

> **Info:** This map summarizes syllabus scope. Upload lectures and tutorials for detailed source-grounded notes and actual tutorial problems.

- Boolean algebra, logic gates and representations
- Multiplexers, encoders, decoders and arithmetic circuits
- Karnaugh-map optimization and don't-care values
- Latches, flip-flops, registers, counters and timing
- Synchronous sequential logic and finite-state machines
- Hardware description and programmable-logic implementation

Study notes should include explanations, justified equations, useful diagrams, checked worked examples, original practice, and common mistakes. Course tools and limitations are listed in the study guidance.
