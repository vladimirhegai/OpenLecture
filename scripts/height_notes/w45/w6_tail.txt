===== practice_problem Textbook P7.1 · RL natural response
The switch has been closed for a long time and opens at $t = 0$.

```schematic
V1 0,3 -> 0,0 "$120\,\mathrm{V}$"
R1 0,3 -> 3,3 "$3\,\Omega$"
R2 3,3 -> 3,0 "$30\,\Omega$"
R3 3,3 -> 6,3 "$6\,\Omega$"
S1 6,3 -> 9,3 "$t=0$" state=closed action=open
L1 9,0 -> 9,3 "$8\,\mathrm{mH}$" i="$i$"
wire 9,3 -> 12,3
R4 12,3 -> 12,0 "$2\,\Omega$"
wire 0,0 -> 3,0 -> 9,0 -> 12,0
ground 0,0
```

1. Calculate the initial value of $i$.
2. Calculate the initial energy stored in the inductor.
3. What is the time constant for $t > 0$?
4. Find $i(t)$ for $t \ge 0$.
5. What percentage of the initial energy has been dissipated in the $2\,\Omega$ resistor $5\,\mathrm{ms}$ after the switch opens?
  STEP: Before $t = 0$ the inductor is a short, which also shorts out the $2\,\Omega$ resistor. The source therefore sees $3\,\Omega$ in series with $30\,\Omega \parallel 6\,\Omega$. | 30 \parallel 6 = 5\,\Omega,\quad i_{src} = \frac{120}{3 + 5} = 15\,\mathrm{A},\quad v_{30} = 75\,\mathrm{V}
  STEP: The $6\,\Omega$ branch carries $\dfrac{75}{6} = 12.5\,\mathrm{A}$ down through the inductor. The reference $i$ points up, so $i$ is negative. A DC operating-point solve confirms the $12.5\,\mathrm{A}$. | i(0^-) = i(0^+) = -12.5\,\mathrm{A}
  STEP: Compute the stored energy. | w(0) = \tfrac12(8\times10^{-3})(12.5)^2 = 0.625\,\mathrm{J}
  STEP: After the switch opens, the inductor sees only the $2\,\Omega$ resistor. | \tau = \frac{L}{R} = \frac{8\times10^{-3}}{2} = 4\,\mathrm{ms}
  STEP: This is a natural response, so it decays to zero. | i(t) = -12.5e^{-250t}\,\mathrm{A},\quad t \ge 0
  STEP: The energy remaining decays as $e^{-\frac{2t}{\tau}}$; the rest has been dissipated in the $2\,\Omega$ resistor. | \frac{w_{diss}}{w(0)} = 1 - e^{-2(5)/4} = 1 - e^{-2.5} \approx 0.918
  ANS: (a) $i(0) = -12.5\,\mathrm{A}$.
(b) $w(0) = 0.625\,\mathrm{J}$.
(c) $\tau = 4\,\mathrm{ms}$.
(d) $i(t) = -12.5e^{-250t}\,\mathrm{A}$ for $t \ge 0$.
(e) About $91.8\%$.
===== practice_problem Textbook P7.22 · RC natural response
The switch has been closed for a long time and opens at $t = 0$.

```schematic
I1 0,0 -> 0,3 "$7.5\,\mathrm{mA}$"
wire 0,3 -> 3,3
R1 3,3 -> 3,0 "$80\,\mathrm{k}\Omega$"
R2 3,3 -> 6,3 "$20\,\mathrm{k}\Omega$"
S1 6,3 -> 9,3 "$t=0$" state=closed action=open
C1 9,3 -> 9,0 "$0.4\,\mu\mathrm{F}$" v="$v(t)$"
wire 9,3 -> 12,3
R3 12,3 -> 12,0 "$50\,\mathrm{k}\Omega$"
wire 0,0 -> 3,0 -> 9,0 -> 12,0
ground 0,0
```

1. Find the initial value of $v(t)$.
2. Find the time constant for $t > 0$.
3. Find $v(t)$ after the switch opens.
4. Find the initial energy stored in the capacitor.
5. How long does it take to dissipate $75\%$ of the initially stored energy?
  STEP: Before $t = 0$ the capacitor is an open circuit. The $7.5\,\mathrm{mA}$ splits between $80\,\mathrm{k}\Omega$ and the $20 + 50 = 70\,\mathrm{k}\Omega$ path by current division. A DC operating-point solve gives the same $200\,\mathrm{V}$. | i_{70k} = 7.5\cdot\frac{80}{80 + 70} = 4\,\mathrm{mA},\quad v(0) = (4\,\mathrm{mA})(50\,\mathrm{k}\Omega) = 200\,\mathrm{V}
  STEP: After the switch opens, the capacitor discharges through the $50\,\mathrm{k}\Omega$ resistor alone. | \tau = RC = (50\times10^{3})(0.4\times10^{-6}) = 20\,\mathrm{ms}
  STEP: This is a natural response. | v(t) = 200e^{-50t}\,\mathrm{V},\quad t \ge 0
  STEP: Compute the initial energy. | w(0) = \tfrac12(0.4\times10^{-6})(200)^2 = 8\,\mathrm{mJ}
  STEP: The remaining energy is $w(0)e^{-\frac{2t}{\tau}}$. Dissipating $75\%$ leaves $25\%$. | e^{-100t} = 0.25 \Rightarrow t = \frac{\ln 4}{100} \approx 13.86\,\mathrm{ms}
  ANS: (a) $v(0) = 200\,\mathrm{V}$.
(b) $\tau = 20\,\mathrm{ms}$.
(c) $v(t) = 200e^{-50t}\,\mathrm{V}$ for $t \ge 0$.
(d) $w(0) = 8\,\mathrm{mJ}$.
(e) $t \approx 13.86\,\mathrm{ms}$.
===== practice_problem Lecture 6 example · RC step response with a two-position switch
The switch has been in position 1 for a long time and moves to position 2 at $t = 0$. It is drawn as two switches that operate together: 1 opens and 2 closes. The $75\,\mathrm{V}$ source has its $+$ terminal at the reference node.

```schematic
V1 0,3 -> 0,0 "$40\,\mathrm{V}$"
R1 0,3 -> 3,3 "$20\,\mathrm{k}\Omega$"
R2 3,3 -> 3,0 "$60\,\mathrm{k}\Omega$"
S1 3,3 -> 6,3 "$1$" state=closed action=open
C1 6,3 -> 6,0 "$0.25\,\mu\mathrm{F}$" v="$v_C$"
S2 9,3 -> 6,3 "$2$" action=close
R3 12,3 -> 9,3 "$8\,\mathrm{k}\Omega$" i="$i_o$"
R4 12,3 -> 12,0 "$160\,\mathrm{k}\Omega$"
R5 12,3 -> 15,3 "$40\,\mathrm{k}\Omega$"
V2 15,0 -> 15,3 "$75\,\mathrm{V}$"
wire 0,0 -> 3,0 -> 6,0 -> 12,0 -> 15,0
label 12,3 "$c$" above
ground 0,0
```

1. Find $v_C(t)$ for $t \ge 0$.
2. Find $i_o(t)$ for $t \ge 0^+$.
  STEP: In position 1 the capacitor is an open circuit at DC and sits across the $60\,\mathrm{k}\Omega$ resistor of a voltage divider (confirmed by a DC solve). | v_C(0^-) = 40\cdot\frac{60}{20 + 60} = 30\,\mathrm{V} = v_C(0^+)
  STEP: In position 2, find the Thévenin equivalent seen by the capacitor. Node $c$ is a divider of the $-75\,\mathrm{V}$ node through $40\,\mathrm{k}\Omega$ and $160\,\mathrm{k}\Omega$, and no current flows in the $8\,\mathrm{k}\Omega$ at steady state. | V_{Th} = -75\cdot\frac{160}{40 + 160} = -60\,\mathrm{V} = v_C(\infty)
  STEP: Zero the $75\,\mathrm{V}$ source (short it) to find the resistance seen by the capacitor. | R_{Th} = 8 + (160 \parallel 40) = 8 + 32 = 40\,\mathrm{k}\Omega
  STEP: Compute the time constant. | \tau = R_{Th}C = (40\times10^{3})(0.25\times10^{-6}) = 10\,\mathrm{ms}
  STEP: Substitute into the general step-response form. | v_C(t) = -60 + [30 - (-60)]e^{-100t} = -60 + 90e^{-100t}\,\mathrm{V},\quad t \ge 0
  STEP: $i_o$ flows through the $8\,\mathrm{k}\Omega$ toward the capacitor, so it enters the capacitor's $+$ terminal and $i_o = C\,\dfrac{dv_C}{dt}$. | i_o = (0.25\times10^{-6})(-9000e^{-100t}) = -2.25e^{-100t}\,\mathrm{mA},\quad t \ge 0^+
  STEP: Check at $0^+$ with the Thévenin circuit. | i_o(0^+) = \frac{V_{Th} - v_C(0^+)}{R_{Th}} = \frac{-60 - 30}{40\,\mathrm{k}\Omega} = -2.25\,\mathrm{mA}
  ANS: (a) $v_C(t) = -60 + 90e^{-100t}\,\mathrm{V}$ for $t \ge 0$.
(b) $i_o(t) = -2.25e^{-100t}\,\mathrm{mA}$ for $t \ge 0^+$.
