[0] <heading> 3e287e92 # Overview

[1] <callout> 3287aa5a info
Week 3 gave you two general solvers, the node-voltage and mesh-current methods. This week is about shortcuts: choosing the cheaper solver, simplifying a circuit by swapping voltage and current sources, and replacing everything a load can "see" by a small Thévenin or Norton equivalent. All three ideas build on the series/parallel reductions of Week 2 and the node and mesh equations of Week 3.

[2] <list> 7eb427e8
- Choose between the node-voltage and mesh-current methods by counting the equations each one needs (Nilsson 4.8).
- Use source transformations to simplify a circuit, and know when a resistor has no effect on the terminal behaviour (Nilsson 4.9).
- Find Thévenin and Norton equivalents for circuits with independent sources and with dependent sources (Nilsson 4.10–4.11).

[3] <heading> a095d659 # Topic 1: Choosing between node-voltage and mesh-current analysis

[4] <paragraph> 86b4f45e
Both methods can solve any planar circuit, but they do not cost the same. The cost is the number of simultaneous equations you must solve, so before writing anything you count the unknowns for each method and take the smaller set.

[5] <paragraph> aab2b594
Let $n_e$ be the number of essential nodes and $b_e$ the number of branches between them. Begin with $n_e-1$ node voltages or $b_e-n_e+1$ mesh currents (planar circuits). Reduce the unknowns using independent source constraints that actually determine a variable, or substitute a dependent source relation expressed in the remaining unknowns. Do not subtract one automatically for every source.

[6] <equation> f0eb32c6
$$N_{\text{node}} = (n_e - 1) - N_{\text{fixed nodes}}, \qquad N_{\text{mesh}} = (b_e - n_e + 1) - N_{\text{fixed meshes}}$$

[7] <paragraph> f50c58b5
The counts below describe the reduced simultaneous system after source relations have been substituted. An independent voltage source to the reference fixes its node voltage; an independent current source belonging to one mesh fixes its mesh current. A dependent source gives a relation, not a known numerical value. Write its controlling voltage or current in terms of the remaining unknowns before counting the reduced equations. Floating voltage sources and shared current sources require supernode or supermesh constraints.

[8] <table> 6e3835ab
| Situation in the circuit | Lean toward | Why |
| A voltage source between the reference node and an essential node | Node-voltage | An independent source fixes that voltage; a dependent source gives a control relation that may allow substitution. |
| A voltage source between two essential nodes (a supernode) | Node-voltage | The source ties two node voltages together, so one can be eliminated (lecture rule: supernodes favour node-voltage). |
| A current source in only one mesh | Mesh-current | The mesh current equals the source current, so there is one fewer unknown. |
| A current source shared by two meshes (a supermesh) | Mesh-current | The source ties two mesh currents together, so one can be eliminated (lecture rule: supermeshes favour mesh-current). |
| Many essential nodes but few meshes, or the reverse | Whichever has the smaller count | Fewer equations means less algebra and fewer chances for a slip. |

[9] <callout> 841c78f0 tip
Method choice rule: count $N_{\text{node}}$ and $N_{\text{mesh}}$ first, then also look at what you are asked for. If the answer is a node voltage or a power in a resistor to ground, node-voltage hands it to you almost directly; if it is a branch current, mesh-current often does.

[10] <callout> a060fd1b warning
Common mistakes: counting every junction as a node instead of only the essential nodes, counting series elements as separate branches, and forgetting that mesh-current analysis needs a planar circuit. Also remember that a dependent source's control variable must be written in terms of your unknowns (for example $i_\Delta = \dfrac{v_c-v_a}{300}$).

[11] <worked_example> 23142947 TITLE: Which method? Power in the 300 Ω resistor
PROMPT: A circuit has independent sources of 256 V and 128 V and a dependent voltage source $50i_\Delta$ controlled by the current in the $300\,\Omega$ resistor. Decide which method needs fewer equations and find the power dissipated in the $300\,\Omega$ resistor.

```schematic
V1 0,4 -> 0,0 "$256\,\mathrm{V}$"
R1 0,4 -> 3,4 "$150\,\Omega$"
R2 3,4 -> 3,0 "$200\,\Omega$"
R3 3,4 -> 6,4 "$100\,\Omega$"
E1 6,4 -> 6,0 "$50i_\Delta$"
R4 6,4 -> 9,4 "$250\,\Omega$"
R5 9,4 -> 9,0 "$400\,\Omega$"
R6 9,4 -> 12,4 "$500\,\Omega$"
V2 12,0 -> 12,4 "$128\,\mathrm{V}$"
wire 3,4 -> 3,6
wire 9,4 -> 9,6
R7 9,6 -> 3,6 "$300\,\Omega$" i="$i_\Delta$"
wire 0,0 -> 12,0
label 3,4 "$a$" below
label 6,4 "$b$" above
label 9,4 "$c$" below
ground 0,0
```

Find:

1. the better method and the number of equations it needs;
2. the power dissipated in the $300\,\Omega$ resistor.
  STEP: Count for mesh-current analysis. There are 4 essential nodes (ground, $a$, $b$, $c$) and 8 branches, so $8 - 4 + 1 = 5$ meshes. No current source fixes a mesh, so mesh-current needs 5 equations.  $$N_{\text{mesh}} = b_e - n_e + 1 = 8 - 4 + 1 = 5$$
  STEP: Count for node-voltage analysis. Taking the bottom wire as reference leaves 3 unknown node voltages, but the dependent source connects node $b$ to ground, so $v_b$ is not independent. Node-voltage needs only 2 equations, so it is the better method.  $$N_{\text{node}} = (4-1) - 1 = 2$$
  STEP: Write the known voltages and the constraint from the dependent source. The 256 V source fixes the left end of the 150 Ω resistor at 256 V, and the 128 V source (negative terminal at the top) fixes the end of the 500 Ω resistor at $-128$ V.  $$i_\Delta = \frac{v_c - v_a}{300}, \qquad v_b = 50\,i_\Delta = \frac{v_c - v_a}{6}$$
  STEP: Apply KCL at node $a$ (all currents leaving) and clear the fractions by multiplying by 600.  $$\frac{v_a-256}{150}+\frac{v_a}{200}+\frac{v_a-v_b}{100}+\frac{v_a-v_c}{300}=0 \;\Rightarrow\; 15v_a - 6v_b - 2v_c = 1024$$
  STEP: Apply KCL at node $c$ and multiply by 6000.  $$\frac{v_c-v_b}{250}+\frac{v_c-v_a}{300}+\frac{v_c}{400}+\frac{v_c+128}{500}=0 \;\Rightarrow\; 71v_c - 24v_b - 20v_a = -1536$$
  STEP: Substitute $6v_b = v_c - v_a$ into both equations to leave two equations in $v_a$ and $v_c$.  $$\begin{aligned} 16v_a - 3v_c &= 1024 \\ -16v_a + 67v_c &= -1536 \end{aligned}$$
  STEP: Add the equations to eliminate $v_a$, then back-substitute.  $$64v_c = -512 \Rightarrow v_c = -8\,\mathrm{V}, \quad v_a = \frac{1024 + 3(-8)}{16} = 62.5\,\mathrm{V}$$
  STEP: Find the control current and the power in the $300\,\Omega$ resistor.  $$i_\Delta = \frac{-8 - 62.5}{300} = -0.235\,\mathrm{A}, \qquad p = i_\Delta^2(300) = 16.57\,\mathrm{W}$$
  ANSWER: Node-voltage is better (2 equations against 5 for mesh-current). $v_a = 62.5\,\mathrm{V}$, $v_c = -8\,\mathrm{V}$, $i_\Delta = -0.235\,\mathrm{A}$, so the $300\,\Omega$ resistor dissipates $p \approx 16.57\,\mathrm{W}$.

[12] <heading> 42e0cd2e # Topic 2: Source transformations

[13] <paragraph> bf4f7c4e
Series and parallel reductions only combine resistors. A source transformation lets you also move between source types: a voltage source in series with a resistor and a current source in parallel with the same resistor look identical from the outside, so you may swap one for the other whenever that makes the circuit easier to reduce.

[14] <heading> 86d13a18 ## The transformation rule

[15] <schematic> ecb6385f {"caption": "Voltage-source form: source $v_s$ in series with $R$.", "citations": [{"chunk_id": "048807fa-dc38-41ac-92f6-8b9d8b5b44d5", "source_id": "67209eb7-82f0-48d1-9be4-753156a96440", "version": 1}], "id": "ecb6385f-75cb-418e-b121-a06dce151fb1", "source": "V1 0,3 -> 0,0 \"$v_s$\"\nR1 0,3 -> 3,3 \"$R$\"\nterminal 3,3 \"$a$\" right\nterminal 3,0 \"$b$\" right\nwire 0,0 -> 3,0", "type": "schematic"}

[16] <schematic> f6e46bff {"caption": "Current-source form: source $i_s$ in parallel with the same $R$.", "citations": [], "id": "f6e46bff-755d-49fe-9f20-c2599280fa26", "source": "I1 0,0 -> 0,3 \"$i_s$\"\nwire 0,3 -> 3,3\nR1 3,3 -> 3,0 \"$R$\"\nwire 3,3 -> 5,3\nterminal 5,3 \"$a$\" right\nwire 0,0 -> 5,0\nterminal 5,0 \"$b$\" right", "type": "schematic"}

[17] <equation> 35522872
$$i_s = \frac{v_s}{R}, \qquad v_s = R\,i_s$$

[18] <paragraph> 21013e9a
Here $v_s$ is the source voltage, $i_s$ the source current and $R$ the one resistor that is in series (voltage form) or in parallel (current form) with the source. The resistor keeps the same value, and the current-source arrow points toward the terminal where the voltage source has its $+$ sign. The rule holds whatever load is attached to $a$ and $b$.

[20] <heading> a96be4ab ## Special cases and power

[21] <paragraph> 8892ea02
A resistor in parallel with an ideal voltage source, or in series with an ideal current source, has no effect on the equivalent circuit seen at the terminals: the source alone fixes the voltage (or current) there. The resistor can therefore be deleted while you find terminal quantities.

[22] <callout> 7f026662 warning
Only the terminal behaviour is preserved. The deleted resistor (and the resistor of a transformed pair) still absorbs power in the real circuit, so power in the original sources must be found by working back to the original circuit. For example, a $125\,\Omega$ resistor across a $250\,\mathrm{V}$ source draws $2\,\mathrm{A}$ that changes the power the source develops even though it does not change $v_o$.

[23] <callout> fb4f5815 warning
Watch polarity: a voltage source with its $+$ at the top becomes a current source pointing up, and the other way round. A source with no series (or parallel) resistor cannot be transformed, and the load itself must never be absorbed into a transformation.

[24] <callout> 19ef716c tip
Strategy: transform toward the part of the circuit you care about, then combine parallel current sources, parallel resistors, series voltage sources and series resistors. Repeat until one loop or one node is left, solve it, and work back through the original circuit for any current, voltage or power you removed along the way.

[25] <worked_example> 69cd6730 TITLE: Source transformations: voltage and powers
PROMPT: Use source transformations to find $v_o$ in the circuit below, then find the power developed by the $250\,\mathrm{V}$ source and by the $8\,\mathrm{A}$ source.

```schematic
V1 0,4 -> 0,0 "$250\,\mathrm{V}$"
R2 3,4 -> 3,0 "$125\,\Omega$"
R1 3,4 -> 7,4 "$25\,\Omega$"
R4 7,4 -> 7,0 "$100\,\Omega$" v="$v_o$"
wire 0,4 -> 3,4
wire 7,4 -> 10,4
I1 10,4 -> 10,2 "$8\,\mathrm{A}$"
R3 10,2 -> 10,0 "$10\,\Omega$"
R5 10,4 -> 13,4 "$5\,\Omega$"
R6 13,4 -> 13,0 "$15\,\Omega$"
wire 0,0 -> 13,0
ground 0,0
```

Find:

1. $v_o$;
2. the power developed by the $250\,\mathrm{V}$ source;
3. the power developed by the $8\,\mathrm{A}$ source.
  STEP: Delete the elements that do not affect $v_o$: the $125\,\Omega$ resistor is in parallel with the $250\,\mathrm{V}$ source, and the $10\,\Omega$ resistor is in series with the $8\,\mathrm{A}$ source.
  STEP: Transform the $250\,\mathrm{V}$ source and its series $25\,\Omega$ resistor into a current source with the same resistor in parallel. The arrow points toward node $b$.  $$i_s = \frac{250}{25} = 10\,\mathrm{A}$$
  STEP: At node $b$ the transformed source pushes $10\,\mathrm{A}$ in and the original source takes $8\,\mathrm{A}$ out, leaving a net $2\,\mathrm{A}$ into $b$.
  STEP: Combine the resistors from $b$ to ground in parallel: $25\,\Omega$, $100\,\Omega$ and the series $5 + 15 = 20\,\Omega$ branch.  $$R_{eq} = \left(\frac{1}{25} + \frac{1}{100} + \frac{1}{20}\right)^{-1} = 10\,\Omega$$
  STEP: Ohm's law across the equivalent resistor gives $v_o$.  $$v_o = (2\,\mathrm{A})(10\,\Omega) = 20\,\mathrm{V}$$
  STEP: Work back to the original circuit for the $250\,\mathrm{V}$ source. The $25\,\Omega$ resistor carries $\dfrac{250-20}{25} = 9.2\,\mathrm{A}$ and the $125\,\Omega$ resistor carries $2\,\mathrm{A}$, both supplied by the source.  $$p_{250} = 250(9.2 + 2) = 2800\,\mathrm{W}\ \text{developed}$$
  STEP: For the $8\,\mathrm{A}$ source the current flows through the $10\,\Omega$ resistor to ground, so $v_d = 80\,\mathrm{V}$. The voltage from $b$ to $d$ is $20 - 80 = -60\,\mathrm{V}$ in the direction of the current, so the source absorbs $-480\,\mathrm{W}$.  $$p_{8\,\mathrm{A}} = (20 - 80)(8) = -480\,\mathrm{W} \;\Rightarrow\; 480\,\mathrm{W}\ \text{developed}$$
  STEP: Check the power balance: the resistors dissipate $500 + 2116 + 4 + 5 + 15 + 640 = 3280\,\mathrm{W}$, which equals $2800 + 480$.
  ANSWER: **(a)** $v_o = 20\,\mathrm{V}$; **(b)** the $250\,\mathrm{V}$ source develops $2800\,\mathrm{W}$; **(c)** the $8\,\mathrm{A}$ source develops $480\,\mathrm{W}$ (total developed $3280\,\mathrm{W}$ = total dissipated).

[26] <heading> 2a5b0fd5 # Topic 3: Thévenin and Norton equivalents

[27] <paragraph> f735dc5e
A linear resistive network that admits a finite Thévenin equivalent behaves at a chosen pair of terminals like a voltage source in series with a resistance. Replacing the network by that pair saves a new analysis for each load. Degenerate ideal sources need care: an ideal current source alone has a Norton form but no finite Thévenin voltage.

[31] <table> 6fd1a1e3
| Term | Meaning |
| Open-circuit voltage $v_{oc}$ | The voltage $v_{ab}$ with nothing connected to $a$ and $b$ (no load current). |
| Short-circuit current $i_{sc}$ | The current from $a$ to $b$ through a wire placed across the terminals. |
| Thévenin voltage $V_{Th}$ | Equals $v_{oc}$, measured with $+$ at $a$. |
| Thévenin resistance $R_{Th}$ | The resistance seen into the terminals; the same value is used in the Norton form, $R_N = R_{Th}$. |
| Norton current $I_N$ | Equals $i_{sc}$, pointing from $b$ to $a$ inside the source. |

[32] <equation> ff5ea7d5
$$V_{Th} = v_{oc}, \qquad I_N = i_{sc}, \qquad R_{Th} = R_N = \frac{v_{oc}}{i_{sc}}, \qquad I_N = \frac{V_{Th}}{R_{Th}}$$

[33] <paragraph> 795109f6
Fix $v_{ab}$ positive at $a$ and define $i_{sc}$ from $a$ to $b$ through the external short. The ratio $\dfrac{v_{oc}}{i_{sc}}$ gives the resistance when $i_{sc}\ne0$. If both are zero, use a test source; $\dfrac{0}{0}$ gives no resistance information. Norton conversion $I_N=\dfrac{V_{Th}}{R_{Th}}$ also requires $R_{Th}\ne0$. For a finite Thévenin equivalent and a nonsingular load, $v_L=\dfrac{V_{Th}R_L}{R_{Th}+R_L}$.

[35] <heading> cdceb6c1 ## Finding the equivalent

[36] <list> 6545a97f
- Compute the open-circuit voltage $v_{ab}$ with the terminals open. This is $V_{Th}$.
- Compute the short-circuit current $i_{sc}$ from $a$ to $b$ with a wire across the terminals.
- Find $R_{Th}=\dfrac{V_{Th}}{i_{sc}}$ when $i_{sc}\ne0$, or use a test source or the independent-source reduction below. Use a test source for $v_{oc}=i_{sc}=0$.
- Draw the Thévenin form ($V_{Th}$ in series with $R_{Th}$) or the Norton form ($i_{sc}$ in parallel with $R_{Th}$).

[37] <paragraph> 5557c03a
If the circuit contains only independent sources, there is a quicker route to $R_{Th}$: deactivate every independent source (replace voltage sources by short circuits and current sources by open circuits) and find the resistance between $a$ and $b$ by series-parallel reduction. If dependent sources are present, deactivate only the independent sources, connect a test source to the terminals and compute the ratio below.

[38] <equation> aedc97ac
$$R_{Th} = \frac{v_T}{i_T}$$

[39] <paragraph> f53dd9e8
Here $v_T$ is a test voltage source placed across $a$–$b$ (or the voltage that results from a test current source) and $i_T$ is the current it pushes into the circuit. Pick whichever test source makes the algebra easier, and solve the circuit for the ratio; the value of $v_T$ or $i_T$ cancels.

[40] <callout> b47353b4 warning
Keep dependent sources active and retain their control relations. Fix $v_{ab}$ positive at $a$ and $i_{sc}$ from $a$ to $b$ in the short. Opposite signs give a negative $R_{Th}$ when the ratio is defined. That can be correct for an active network with dependent sources; verify it with a test source. In a network containing only positive resistors and independent sources, it indicates a sign or analysis error.

[41] <callout> dbc6a377 tip
With only independent sources, deactivate them and find the resistance seen at the terminals. With dependent sources, retain them and use a test source, or use $\dfrac{v_{oc}}{i_{sc}}$ if $i_{sc}\ne0$. An already computed, nonzero short-circuit current makes the ratio a useful cross-check.

[42] <worked_example> 7266b713 TITLE: Thévenin and Norton equivalents, independent sources
PROMPT: Find the Thévenin and Norton equivalent circuits with respect to terminals $a$ and $b$.

```schematic
V1 0,4 -> 0,0 "$25\,\mathrm{V}$"
R1 0,4 -> 4,4 "$5\,\Omega$"
R2 4,4 -> 4,0 "$20\,\Omega$"
wire 4,4 -> 7,4
I1 7,0 -> 7,4 "$3\,\mathrm{A}$"
R3 7,4 -> 11,4 "$4\,\Omega$"
terminal 11,4 "$a$" right
terminal 11,0 "$b$" right
gap 11,4 -> 11,0 v="$v_{ab}$"
label 4,4 "$v_1$" above
wire 0,0 -> 11,0
ground 0,0
```

Find $V_{Th}$, $R_{Th}$, the Norton current $I_N$, and check $R_{Th}$ by deactivating the sources.
  STEP: Open circuit: no current flows in the $4\,\Omega$ resistor, so $V_{Th} = v_1$. Apply KCL at node $n$, with the $3\,\mathrm{A}$ source entering.  $$\frac{v_1 - 25}{5} + \frac{v_1}{20} = 3 \;\Rightarrow\; 5v_1 = 160 \;\Rightarrow\; V_{Th} = v_{oc} = 32\,\mathrm{V}$$
  STEP: Short circuit: the $4\,\Omega$ resistor now connects node $n$ to ground, so it carries the short-circuit current. Repeat KCL with this extra branch.  $$\frac{v_1 - 25}{5} + \frac{v_1}{20} + \frac{v_1}{4} = 3 \;\Rightarrow\; 10v_1 = 160 \;\Rightarrow\; v_1 = 16\,\mathrm{V}$$
  STEP: The short-circuit current is the current in the $4\,\Omega$ resistor.  $$i_{sc} = \frac{16}{4} = 4\,\mathrm{A}$$
  STEP: Divide the open-circuit voltage by the short-circuit current.  $$R_{Th} = \frac{v_{oc}}{i_{sc}} = \frac{32}{4} = 8\,\Omega$$
  STEP: Check by deactivating the sources: the $25\,\mathrm{V}$ source becomes a short and the $3\,\mathrm{A}$ source an open circuit, leaving $5\,\Omega$ in parallel with $20\,\Omega$ in series with $4\,\Omega$.  $$R_{Th} = (5 \parallel 20) + 4 = 4 + 4 = 8\,\Omega$$
  STEP: Draw the equivalents: the Thévenin circuit is a $32\,\mathrm{V}$ source ($+$ at $a$) in series with $8\,\Omega$; the Norton circuit is a $4\,\mathrm{A}$ source pointing toward $a$ in parallel with $8\,\Omega$.
  ANSWER: $V_{Th} = 32\,\mathrm{V}$, $R_{Th} = 8\,\Omega$; Norton: $I_N = 4\,\mathrm{A}$ in parallel with $R_N = 8\,\Omega$.

[43] <heading> 52200d38 ## Circuits with dependent sources

[44] <paragraph> cd851b98
A dependent source follows a voltage or current elsewhere in the circuit, so it cannot be "turned off" and the control variable has to be solved together with everything else. The open-circuit and short-circuit calculations still work, and the test-source method gives a cross-check for $R_{Th}$. It is also possible for $V_{Th}$ and $i_{sc}$ to both be negative, which is fine: the ratio $R_{Th}$ is then still positive.

[45] <worked_example> e94d55f5 TITLE: Thévenin equivalent with a dependent source
PROMPT: Find the Thévenin equivalent with respect to terminals $a$ and $b$.

```schematic
V1 0,4 -> 0,0 "$5\,\mathrm{V}$"
R1 0,4 -> 4,4 "$2\,\mathrm{k}\Omega$" i="$i$"
E1 4,4 -> 4,0 "$3v$"
G1 7,4 -> 7,0 "$20i$"
wire 7,4 -> 10,4
R2 10,4 -> 10,0 "$25\,\Omega$" v="$v$"
wire 10,4 -> 13,4
terminal 13,4 "$a$" right
terminal 13,0 "$b$" right
wire 0,0 -> 13,0
ground 0,0
```

Find $V_{Th}$, $i_{sc}$ and $R_{Th}$, and check $R_{Th}$ with a test source.
  STEP: Open circuit: the $25\,\Omega$ resistor and the dependent current source are the only elements at node $a$, so their currents must cancel.  $$\frac{v}{25} + 20i = 0 \;\Rightarrow\; v = -500\,i$$
  STEP: The left loop contains the $5\,\mathrm{V}$ source, the $2\,\mathrm{k}\Omega$ resistor and the dependent source $3v$. Apply KVL.  $$5 = 2000\,i + 3v$$
  STEP: Substitute $v = -500\,i$ and solve for the current, then for $v$.  $$5 = 2000i - 1500i \Rightarrow i = 10\,\mathrm{mA}, \quad V_{Th} = v_{oc} = -5\,\mathrm{V}$$
  STEP: Short circuit: $v = 0$, so the dependent voltage source $3v$ is $0$ and the loop current is set by the $5\,\mathrm{V}$ source alone.  $$i = \frac{5}{2000} = 2.5\,\mathrm{mA}$$
  STEP: With the $25\,\Omega$ resistor shorted, the dependent current source $20i = 50\,\mathrm{mA}$ pulls current down from $a$, and the wire must supply it from $b$. Measured from $a$ to $b$, the short-circuit current is therefore negative.  $$i_{sc} = -20i = -50\,\mathrm{mA}$$
  STEP: Divide the open-circuit voltage by the short-circuit current.  $$R_{Th} = \frac{-5}{-0.05} = 100\,\Omega$$
  STEP: Check with a test source: replace the $5\,\mathrm{V}$ source by a short, apply $v_T$ at $a$–$b$ so $v = v_T$, and note $i = -\dfrac{3v_T}{2000}$. KCL at $a$ gives the current $i_T$ that the test source supplies.  $$i_T = \frac{v_T}{25} + 20i = v_T(0.04 - 0.03) = \frac{v_T}{100} \;\Rightarrow\; R_{Th} = \frac{v_T}{i_T} = 100\,\Omega$$

[55] <heading> 8369e411 # Summary

[56] <list> c45ed914
- Count the equations before you start: node-voltage needs $(n_e - 1)$ minus the nodes fixed by voltage sources; mesh-current needs $(b_e - n_e + 1)$ minus the meshes fixed by current sources. Count dependent control constraints after substitution; a source does not automatically remove an unknown.
- Supernodes favour node-voltage and supermeshes favour mesh-current, because the source ties two unknowns together and one can be eliminated.
- A source transformation swaps a voltage source in series with $R$ for a current source in parallel with $R$ using $i_s = \dfrac{v_s}{R}$, and keeps the terminal behaviour unchanged.
- A resistor in parallel with an ideal voltage source or in series with an ideal current source does not change the terminal equivalent, but it does change power, so work back to the original circuit for powers.
- For a linear resistive port with a finite equivalent, $V_{Th}=v_{oc}$ and $I_N=i_{sc}$. Use $R_{Th}=\dfrac{v_{oc}}{i_{sc}}$ only for $i_{sc}\ne0$, and a test source when both are zero.
- With independent sources only, find $R_{Th}$ by zeroing the sources; with dependent sources present, keep them and use a test source, $R_{Th} = \dfrac{v_T}{i_T}$, or the ratio $\dfrac{v_{oc}}{i_{sc}}$.
- Signs matter: $v_{ab}$ is positive at $a$, $i_{sc}$ flows from $a$ to $b$, and a negative $V_{Th}$ with a negative $i_{sc}$ still gives a positive $R_{Th}$.
