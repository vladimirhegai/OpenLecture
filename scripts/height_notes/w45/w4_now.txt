[1] <callout> 3287aa5a info
Three shortcuts this week. **Pick the cheaper method** (node or mesh). **Swap sources** ($V$ + series $R$ ⇄ $I$ ∥ $R$). **Shrink a circuit to two numbers** a load can see: $V_{\mathrm{Th}}$ and $R_{\mathrm{Th}}$. [8] <heading> 6e3835ab # Topic 1: Node or mesh?

[9] <list> 841c78f0
- **Node:** unknowns $=(n_e-1)$, minus every height a voltage source fixes. A supernode still saves one.
- **Mesh:** unknowns $=(b_e-n_e+1)$, minus every mesh current a current source fixes. A supermesh saves one.
- A dependent source adds no unknown once its control is written in your unknowns.
- Tie-break: asked for a node voltage → node; asked for a branch current → mesh.

[10] <equation> a060fd1b
$$\begin{aligned}N_{\text{node}}&=(n_e-1)-(\text{fixed heights})\\N_{\text{mesh}}&=(b_e-n_e+1)-(\text{fixed meshes})\end{aligned}$$

[14] <heading> 86d13a18 # Topic 2: Source transformations

[15] <list> ecb6385f
- A voltage source $v_s$ **in series** with $R$ ⇄ a current source $i_s=\dfrac{v_s}{R}$ **in parallel** with the same $R$. The arrow points to the $+$ end.
- **Same terminal height for every load.** The inside is different: never take a source's power from the swapped circuit.
- $R$ **across** an ideal voltage source: changes no other height (drop it; it still burns power). $R$ **in series** with an ideal current source: changes only the height between them (drop it).
- Strategy: swap toward what you want; merge parallel current sources and series voltage sources; repeat; go back to the original for powers.

[16] <equation> f6e46bff
$$i_s=\frac{v_s}{R},\qquad v_s=R\,i_s$$

[22] <heading> 7f026662 # Topic 3: Thévenin and Norton

[23] <list> fb4f5815
- Seen from $a$–$b$, any linear circuit is **one step $V_{\mathrm{Th}}$ and one slope $R_{\mathrm{Th}}$**.
- $V_{\mathrm{Th}}$ = height of $a$ with nothing attached. $I_N$ = current through a wire from $a$ to $b$.
- $R_{\mathrm{Th}}=\dfrac{V_{\mathrm{Th}}}{I_N}$. Or: sources off (voltage → wire, current → gap), push $1\,\mathrm{A}$ into $a$, read $a$'s height.
- A load draws $i$, so $a$ **sags**: $v_{ab}=V_{\mathrm{Th}}-R_{\mathrm{Th}}i$. Norton = the source transformation: $I_N$ ∥ $R_{\mathrm{Th}}$.
- Ground $b$, so $a$'s height is $v_{ab}$ (if a node dips below $b$, ground the lowest node and subtract).
- Dependent sources inside? Keep them on. That is Week 5 Topic 1.

[24] <equation> 19ef716c
$$V_{\mathrm{Th}}=v_{oc},\qquad I_N=i_{sc},\qquad R_{\mathrm{Th}}=\frac{V_{\mathrm{Th}}}{I_N},\qquad v_{ab}=V_{\mathrm{Th}}-R_{\mathrm{Th}}\,i$$
