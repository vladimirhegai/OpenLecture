[0] <heading> 76cdf006 # Overview

[1] <callout> a97684fe info
Week 3 gives two systematic ways to solve circuits that don't reduce to series and parallel. **Node voltages:** name the unknown node heights, write KCL at each. **Mesh currents:** give each window of the circuit a loop current, write KVL around each. The node-voltage method *is* the height method, written as equations.

[8] <worked_example> eb53b1af TITLE: S1 · One unknown height
PROMPT: Find the height of $x$, every current, and the power of each source.

```schematic
V1 0,3 -> 0,0 "$10\,\mathrm{V}$"
R1 0,3 -> 3,3 "$2\,\Omega$"
R2 3,3 -> 3,0 "$4\,\Omega$" flip
wire 3,3 -> 6,3
I1 6,0 -> 6,3 "$1\,\mathrm{A}$" flip
wire 6,0 -> 0,0
label 3,3 "$x$" above
ground 0,0
#@ step "Rule 1: ground the bottom wire. Rule 2: the source puts the top at $10\,\mathrm{V}$."
#@ step "Rule 3: the current source pushes $1\,\mathrm{A}$ into $x$, whatever $x$'s height is. Call that height $x$." show=eI1
#@ step "Rules 4 and 5: KCL at $x$. In through the $2\,\Omega$, plus the $1\,\mathrm{A}$ = out down the $4\,\Omega$: $\dfrac{10-x}{2}+1=\dfrac{x}{4}$, so $x=8\,\mathrm{V}$." show=x
#@ step "Currents = fall ÷ R: the $2\,\Omega$ falls $2\,\mathrm{V}$ ($1\,\mathrm{A}$), the $4\,\Omega$ falls $8\,\mathrm{V}$ ($2\,\mathrm{A}$). KCL: $1+1=2$." show=eR1,eR2,eV1
#@ step "Power = current × height change. Both sources climb: $(1)(10)+(1)(8)=18\,\mathrm{W}$. The falls absorb $(2)(1)+(8)(2)=18\,\mathrm{W}$."
```
  STEP: Ground the bottom wire; the top is at $10\,\mathrm{V}$. Call the middle height $x$.
  STEP: KCL at $x$: in through the $2\,\Omega$ plus the $1\,\mathrm{A}$ pushed in = out down the $4\,\Omega$.  $$\frac{10-x}{2}+1=\frac{x}{4}\;\Rightarrow\;20-2x+4=x\;\Rightarrow\;x=8\,\mathrm{V}$$
  STEP: Currents = fall ÷ R.  $$i_{2\Omega}=\frac{10-8}{2}=1\,\mathrm{A},\qquad i_{4\Omega}=\frac{8}{4}=2\,\mathrm{A}$$
  STEP: Power: climbs = falls.  $$(10)(1)+(8)(1)=18\,\mathrm{W}=(2)(1)+(8)(2)$$
  ANSWER: $x=8\,\mathrm{V}$; $1\,\mathrm{A}$ through the $2\,\Omega$, $2\,\mathrm{A}$ down the $4\,\Omega$. The sources deliver $10+8=18\,\mathrm{W}$; the resistors absorb $18\,\mathrm{W}$.

[10] <heading> 8ff38f87 # Topic 1: Circuit terminology

[11] <table> 42b7570f
| Term | Meaning | In heights |
| Node | a connected wire, however many bends | one level |
| Essential node | three or more elements meet | an unknown height to solve for (minus ground) |
| Branch / essential branch | one element / a path between essential nodes | one element / one column between two unknown levels |
| Loop / mesh | a closed path / a loop with no loop inside it | a loop walk returns to its starting height |
| Planar | can be drawn with no crossings | needed for meshes only |

[12] <equation> 71784ed9
$$\text{node equations}=n_e-1,\qquad \text{meshes}\;M=b-n+1=b_e-n_e+1$$

[13] <list> 874557b6
- Node-voltage method: one KCL per essential node **except ground** ($n_e-1$ unknown heights).
- Mesh-current method: one KVL per mesh ($M$ loop currents). Planar circuits only.
- A crossing without a dot is not a connection. Two elements between the same two nodes are still two branches.
- A known source fixes one unknown: a voltage source to ground fixes a height; a current source on a mesh edge fixes a mesh current.

[16] <heading> 17261c87 # Topic 2: The node-voltage method

[17] <list> 17525f4b
- **Recipe:** ground one node → name every unknown height → KCL at each (currents out $=\dfrac{v_k-v_j}{R}$) → solve → currents = fall ÷ R → check power.
- Pick ground at the node with the most connections, or the $-$ end of a voltage source (then that source fixes a height for free).
- **Averaging rule:** a node joined only by resistors sits at the **conductance-weighted average** of its neighbours' heights, lifted by any current pushed into it. One unknown node? This *is* the KCL answer.
- So with only voltage sources and resistors, no node rises above the highest source. **Current sources can** push a node higher.

[18] <equation> 86730c44
$$\text{KCL at }k:\;\sum_j\frac{v_k-v_j}{R_{kj}}=I_{\text{in}}\qquad\Longleftrightarrow\qquad v_k=\frac{\sum_j G_j v_j+I_{\text{in}}}{\sum_j G_j},\quad G=\frac{1}{R}$$

[19] <worked_example> 50c3a254 TITLE: One node, three neighbours (Lecture 3)
PROMPT: Use the node-voltage method to find $i_a$, $i_b$ and $i_c$.

```schematic
V1 0,3 -> 0,0 "$50\,\mathrm{V}$"
R1 0,3 -> 3,3 "$5\,\Omega$" i="$i_a$"
R2 3,3 -> 3,0 "$10\,\Omega$" i="$i_b$"
wire 3,3 -> 6,3
R3 6,3 -> 6,0 "$40\,\Omega$" i="$i_c$"
wire 6,3 -> 9,3
I1 9,0 -> 9,3 "$3\,\mathrm{A}$"
wire 9,0 -> 0,0
label 3,3 "$a$" above
ground 0,0
#@ step "Ground the bottom wire; the source fixes the left end of the $5\,\Omega$ at $50\,\mathrm{V}$. Only $a$'s height is unknown."
#@ step "Averaging rule: $a$ is joined to $50\,\mathrm{V}$ (through $5\,\Omega$) and to ground twice ($10$, $40\,\Omega$), with $3\,\mathrm{A}$ pushed in: $a=\dfrac{50/5+3}{1/5+1/10+1/40}=\dfrac{13}{0.325}=40\,\mathrm{V}$." show=a
#@ step "Currents = fall ÷ R: $i_a=\dfrac{10}{5}=2$, $i_b=\dfrac{40}{10}=4$, $i_c=\dfrac{40}{40}=1\,\mathrm{A}$. KCL at $a$: $2+3=4+1$." show=eR1,eR2,eR3,eV1,eI1
#@ step "Power: the voltage source lifts $2\,\mathrm{A}$ through $50\,\mathrm{V}$ ($100\,\mathrm{W}$), the current source $3\,\mathrm{A}$ through $40\,\mathrm{V}$ ($120\,\mathrm{W}$); the falls absorb $20+160+40=220\,\mathrm{W}$."
```
  STEP: Ground the bottom wire; only $a$ is unknown. KCL at $a$, currents out; the $3\,\mathrm{A}$ comes in.  $$\frac{v_a-50}{5}+\frac{v_a}{10}+\frac{v_a}{40}=3$$
  STEP: Multiply by 40 and solve.  $$8v_a-400+4v_a+v_a=120\;\Rightarrow\;v_a=40\,\mathrm{V}$$
  STEP: Currents = fall ÷ R, in the arrow directions.  $$i_a=\frac{50-40}{5}=2\,\mathrm{A},\quad i_b=4\,\mathrm{A},\quad i_c=1\,\mathrm{A}$$
  STEP: Check KCL at $a$.  $$2+3=4+1$$
  ANSWER: $v_a=40\,\mathrm{V}$; $i_a=2\,\mathrm{A}$, $i_b=4\,\mathrm{A}$, $i_c=1\,\mathrm{A}$

[23] <heading> a508fb6f # Topic 3: Fixed heights, supernodes and dependent sources

[24] <list> a4da19f8
- **Voltage source to ground:** it fixes that node's height. No equation for it.
- **Voltage source between two unknown nodes (supernode):** a **rigid rod**. It locks their difference ($v_p-v_q=V_s$) but the rod floats until **KCL around the whole rod** pins it. The rod's own current stays inside: leave it out.
- **Dependent source:** write its control in node heights first (e.g. $i_\Phi=\dfrac{v_a-v_b}{R}$), then treat it like any source. A dependent voltage source is a rod whose length you read off the picture.
- Dependent sources often **absorb** (current falls through them). Read it off the arrow colour.

[25] <equation> 1ac75ca0
$$\text{rod: }v_p-v_q=V_s\qquad\qquad \text{KCL around the rod: }\sum i_{\text{out of the rod}}=0$$

[32] <heading> d828a7f0 # Topic 4: The mesh-current method

[33] <list> ef757ca4
- **Recipe:** a clockwise current in each window → one **loop walk** (KVL) per mesh → solve → branch currents → heights → power.
- **In heights:** a loop walk is "climbs = falls" around the window. Mesh currents themselves have **no** height: they are bookkeeping. Only branch currents are real.
- A resistor shared by two meshes carries the **difference**: $I_k-I_\ell$ in mesh $k$'s direction.
- **Current source on the edge** of one mesh: it fixes that mesh current (watch the arrow vs clockwise).
- **Current source shared** by two meshes: its step is unknown, so the walk **skips** it: walk around both meshes together (supermesh) and add $I_a-I_b=I_s$.
- Once branch currents are known, walk down the falls to place every height. That also gives a current source's step for free.

[34] <equation> 263a2e3f
$$\text{shared }R:\;i=I_k-I_\ell,\qquad\text{supermesh: }I_a-I_b=I_s$$

  STEP: Solve with the control.  $$i_1=4\,\mathrm{A},\quad i_2=-1\,\mathrm{A},\quad i_3=3\,\mathrm{A},\quad v_\phi=12\,\mathrm{V}$$
  STEP: The diamond carries $i_2$; absorbed power with current entering $-$ means delivering.  $$p=-(-3v_\phi)\,i_2=3(12)(-1)=-36\,\mathrm{W}$$

[55] <heading> e42e1108 ## B · Fixed heights and rigid rods

[56] <list> ea0c60cb
- Voltage source to ground: that height is **given**.

- Dependent source: write the control in heights first; then it is a rod (voltage) or a pump (current).

[58] <heading> 858a58db ## C · Mesh currents are loop walks

[59] <list> c1b3d759
- Clockwise current per window; KVL = walk the window, climbs = falls.
- A shared resistor carries $I_k-I_\ell$. A shared current source: skip it (supermesh) and add $I_a-I_b=I_s$.
- Mesh currents have no height. Turn them into branch currents, then walk down the falls to place the heights.

[66] <heading> af069807 # Extra: many sources at once

[67] <list> a96145c7
- **No source is "the main one".** Only ground is special. Every source is just one more element on the picture.
- **Each voltage source** fixes a height (one end grounded) or a rigid rod (between two unknown nodes). Two batteries → two fixed heights. The Straight line view uses the tallest as the rail and draws the rest as steps.
- **Each current source** fixes a current, never a height. Arrow **into** a node pushes it up; arrow **out of** a node drags it down. No voltage source at all? Then *every* height is unknown and comes from KCL.
- **Then the usual recipe:** ground → fixed heights → name the unknown heights → KCL at each → solve → currents = fall ÷ R → power.
- **Sanity check:** a node can only rise above every voltage source, or sink below ground, when a current source (or dependent source) puts it there.
- This *is* nodal analysis: the node voltages are the heights, and each KCL equation says "what falls in = what falls out". See also AP 4.13 (two batteries + a pump) and P4.13 (two pumps, no battery).
