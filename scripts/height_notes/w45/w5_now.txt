**Signs.** $V_{\mathrm{Th}}<0$ means $a$ sits **below** $b$ when nothing is attached; then $I_N<0$ too (it flows $b\to a$) and $R_{\mathrm{Th}}=\dfrac{V_{\mathrm{Th}}}{I_N}$ stays positive.

[9] <heading> 27813ac5 # Topic 1: Thévenin with dependent sources

[10] <list> f431eb2a
- A dependent source **can't be turned off**: keep it in every picture, with its control.
- **Test source:** independent sources off, push $1\,\mathrm{A}$ into $a$. $a$'s height per amp $=R_{\mathrm{Th}}$.
- **One shot (all sources on):** push $i_T$ into $a$; then $a=V_{\mathrm{Th}}+R_{\mathrm{Th}}\,i_T$. Intercept = $V_{\mathrm{Th}}$, slope = $R_{\mathrm{Th}}$.
- **No independent source** → nothing lifts $a$: $V_{\mathrm{Th}}=0$, $I_N=0$. Only a test source gives $R_{\mathrm{Th}}$.
- **$R_{\mathrm{Th}}$ can be negative:** pull current out of $a$ and $a$ *rises*. The dependent source is delivering; don't draw it as a slope.
- Keep a dependent source and its control on the same side of $a$–$b$.

[11] <equation> a9a2adda
$$R_{\mathrm{Th}}=\frac{v_T}{i_T}\;(\text{independent sources off}),\qquad v_T=V_{\mathrm{Th}}+R_{\mathrm{Th}}\,i_T\;(\text{all on})$$

[12] <table> a1ad7848
| Inside the circuit | Fastest route to $R_{\mathrm{Th}}$ |
| independent sources only | sources off, combine resistors (or $V_{\mathrm{Th}}/I_N$) |
| independent + dependent | $V_{\mathrm{Th}}/I_N$, or a test source |
| dependent only | test source ($V_{\mathrm{Th}}=I_N=0$) |

[17] <heading> bdf37011 # Topic 2: Maximum power transfer

[18] <list> 6862b41a
- A load on a Thévenin source sits at height $h$. It gets current $\dfrac{V_{\mathrm{Th}}-h}{R_{\mathrm{Th}}}$, so $p=h\cdot\dfrac{V_{\mathrm{Th}}-h}{R_{\mathrm{Th}}}$.
- $h$ and $V_{\mathrm{Th}}-h$ add to $V_{\mathrm{Th}}$. Their product is largest when they are equal: **$h=\dfrac{V_{\mathrm{Th}}}{2}$**, which happens at $R_L=R_{\mathrm{Th}}$.
- Half of $V_{\mathrm{Th}}$, **not** half of the supply.
- Max power ≠ max efficiency: at the match $R_{\mathrm{Th}}$ burns as much as the load, and the real sources may waste more. For efficiency, go back to the original circuit.
- Load fixed, series $R$ adjustable? That $R$ only steals height: pick $0$.

[19] <equation> 95488e52
$$R_L=R_{\mathrm{Th}},\qquad h=\frac{V_{\mathrm{Th}}}{2},\qquad p_{\max}=\frac{V_{\mathrm{Th}}^2}{4R_{\mathrm{Th}}}$$

[24] <heading> 523c34c4 # Topic 3: Superposition

[25] <list> 2b9cbdd1
- Linear circuit: every voltage and current = the sum of what each **independent** source makes alone.
- One picture per source. Other voltage sources → wires; other current sources → gaps (left out of the pictures below). **Dependent sources stay on.**
- **Add voltages (height differences) and currents. Never powers:** $p$ is current × fall, a product. Compute it once from the sums.
- Keep the same reference directions in every picture. A partial picture may run a resistor "backwards"; only the sum must run downhill.
- Worth it when each one-source picture is a divider or a series–parallel reduction.

[26] <equation> 8842f977
$$y=y_1+y_2+\cdots,\qquad p=(v_1+v_2)(i_1+i_2)\neq p_1+p_2$$
